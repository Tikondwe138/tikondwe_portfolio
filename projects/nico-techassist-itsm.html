NICO TechAssist ITSM

Overview

A production-oriented, multi-tenant IT Service Management (ITSM) platform designed for Managed Service Providers (MSPs) and internal IT departments to manage support tickets, IT assets, service-level agreements, technician assignments, and operational history from a centralized system.

Reference Case Notice: This platform is being developed as an independent software project, using NICO Technologies Limited as a reference use case for an MSP environment. It is not commissioned, owned, endorsed, or operated by NICO Technologies Limited.

Problem Statement

IT support operations become difficult to scale when service requests, hardware assets, technician assignments, SLA commitments, and historical records are fragmented across spreadsheets, messaging platforms, email, and disconnected systems.

NICO TechAssist addresses this challenge by providing a structured platform for managing the complete IT service lifecycle while maintaining organizational separation, strict tenant access controls, and complete operational traceability.

Proposed Architecture

The platform is developed using a layered Flask architecture with PostgreSQL as the primary database engine. The architecture explicitly separates authentication, authorization, tenant isolation, API routes, business services, database models, validation schemas, error handling, and supporting utilities.

The multi-tenant design enables an MSP environment to support multiple client organizations concurrently while strictly restricting users to the organizations and resources they are explicitly authorized to access.
